# AVL Tree - Java DSA

## Author

T. Ruchitha

## Description

This program implements an AVL Tree in Java. An AVL Tree is a self-balancing Binary Search Tree that maintains its balance after insertion using rotations.

## Technology

- Data Structures
- Algorithms

- Binary Search Tree

## Algorithm

AVL Tree Insertion

## File Name

AVLTree.java

## Input

Insert: 30 20 10 25 28 27

## Output

Inorder Traversal:
10 20 25 27 28 30
